# Aerolith fonts

The two typefaces from [Aerolith](https://immineal.github.io/aerolith/), as TTF files to install
on your computer. Download them all as `aerolith-fonts.zip` from the
[latest release](https://github.com/immineal/aerolith/releases/latest/download/aerolith-fonts.zip).

**Aerolith Text** is Selawik with a kern table added. Light, Regular, Semibold and Bold, 348
characters (Latin with accents).

**Aerolith Display** is gel lettering rendered in Bryce, one colour font per material: Aqua,
Glass, Glass Dark (for dark backgrounds) and Pearl. The glyphs are bitmaps drawn at about 80 px
per em, so set them large, 32 px and up. It covers A–Z, a–z, digits, ASCII punctuation, German
umlauts and ß, à ç è é ñ, curly quotes, dashes, … and €. The files are OpenType-SVG, which
Windows, macOS, Adobe apps and Firefox draw in colour. Apps without colour-font support show plain
heavy letters instead.

For web pages you don't need these: `aerolith.css` loads the WOFF2 versions from
`library/dist/fonts/`.

Both fonts are under the SIL Open Font License 1.1, see the `OFL-*.txt` files.
